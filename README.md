# Octane Browser

A lightweight desktop web browser built with Python and PyQt5 utilizing the QtWebEngineView component.

## Features

- **Full Web Rendering:** Powered by Chromium through QtWebEngine for modern HTML5, CSS3, and JavaScript support.
- **Navigation Controls:** Back, Forward, Reload, Home buttons, and combined URL/search bar.
- **Tabbed Browsing:** Multi-tab browsing capabilities with dynamic tab closure.

## Tech Stack

- Python 3.8+
- PyQt5 & PyQtWebEngine

## Run

```bash
pip install PyQt5 PyQtWebEngine
python main.py
```
